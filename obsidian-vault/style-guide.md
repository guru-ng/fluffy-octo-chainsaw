## What Claude Should Always Do

- Match the frontmatter format: `title`, `description`, `publishDate: "DD Mon YYYY"`, `tags: [...]`
- Keep descriptions under 160 characters (used as meta description)
- Place the file in `src/content/post/<slug>/index.md` or `src/content/post/<slug>.md`

## What Claude Should Never Do

- Add a "Conclusion" section header
- Use em-dash spam
- Write a listicle when a short narrative works better
- Start a sentence with "In today's world"
